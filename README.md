# 🛒 Market Basket Analysis – Online Retail Dataset (R) 

## 📌 Project Overview

This project performs Market Basket Analysis (MBA) using the Apriori algorithm on the Online Retail dataset. The objective is to uncover product association patterns and generate business insights based on customer purchasing behavior across different regions. The analysis focuses on the top three countries by transaction volume:
United Kingdom, Germany, and France.

## The project includes:

- Data cleaning and preprocessing

- Exploratory data analysis (EDA)

- Formation of transaction baskets

- Apriori association rule mining

- Country-wise interpretation and business recommendations

## 📦 Technologies Used

| Tool      | Purpose                             |
| --------- | ----------------------------------- |
| R         | Data processing, visualization, MBA |
| tidyverse | Cleaning, transformation            |
| arules    | Apriori algorithm                   |
| ggplot2   | EDA visualization                   |

## 🧾 Conclusion

MBA revealed valuable insights into customer purchasing patterns that can support strategic bundling, regional marketing, and inventory planning. Country-specific behavior highlights opportunities for localized product positioning and cross-selling initiatives.
